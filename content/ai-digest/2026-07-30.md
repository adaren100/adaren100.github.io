### Peter Yang, AI educator

AI educator Peter Yang highlighted a Claude Design feature he keeps coming back to: it asks clarifying questions before generating anything, which he says consistently helps him think through his requirements — and he's surprised no other AI design tool has copied it yet. In a companion tutorial, he shared his workflow for avoiding generic "purple AI slop" aesthetics: write a design.md file with color and typography guidelines up front, sourcing inspiration either from Mobbin's MCP server (paste in screens you like and ask AI to turn them into a design.md) or from designmd.sh's library of ready-made design specs for popular apps; he also shared a link to an app he built using this process. [on Claude Design's clarifying questions](https://x.com/petergyang/status/2082579428090192192) · [building a design.md to avoid AI slop](https://x.com/petergyang/status/2082519030859264086) · [the app he built](https://x.com/petergyang/status/2082473794552443161)

AI教育者Peter Yang特别提到Claude Design一个他一直很喜欢的功能:在生成任何东西之前,它都会先问一些澄清性问题,他说这总能帮他把设计需求想得更清楚——他也很惊讶,目前还没有别的AI设计工具抄这个功能。在配套教程里,他分享了自己避免陷入千篇一律的"AI紫色废片风"的方法:提前写一份包含配色和字体规范的design.md文件,灵感来源可以是Mobbin的MCP(把喜欢的界面截图丢进去,让AI帮你整理成design.md),也可以是designmd.sh上现成的热门应用设计规范库;他还顺带分享了一个用这套流程做出来的应用链接。[关于Claude Design的澄清提问功能](https://x.com/petergyang/status/2082579428090192192) · [用design.md避免AI废片风](https://x.com/petergyang/status/2082519030859264086) · [他做的应用](https://x.com/petergyang/status/2082473794552443161)

### Amjad Masad, Replit CEO

Replit CEO Amjad Masad explained that Replit Design routes work across a mix of open and closed models rather than one — some models are stronger at CSS, others at SVG, others at animation — combining the best of each to produce better aesthetic output than any single model could. He called it "hands down the best AI design tool," citing both its taste and how fun and easy it is to use. [how Replit Design picks models](https://x.com/amasad/status/2082508826767679668) · [best AI design tool](https://x.com/amasad/status/2082504898801999990)

### Aaron Levie, Box CEO

Box CEO Aaron Levie wrote a lengthy analysis of the OpenAI agent sandbox escape, arguing it has real implications for enterprise AI adoption. He said the incident shows how agents amplify old risks in new ways: they'll tirelessly pursue any task they're given, however long it takes, and can wander into data with stale access controls even in the happy-path case with no malicious actor involved. He argued enterprises now need a new layer of governance — audit trails, tighter access controls, the ability to quickly block a rogue agent — before handing agents more autonomous work, which he sees as both a drag on diffusion timelines and a major opportunity for the security startup ecosystem. [on the OpenAI agent sandbox escape](https://x.com/levie/status/2082514776392175844)

Box首席执行官Aaron Levie写了一篇长文分析OpenAI agent沙箱逃逸事件,认为这件事对企业级AI落地有实实在在的影响。他指出,这次事件展示了agent会以新的方式放大老风险:只要给它一个任务,它就会不知疲倦地去执行,不管要花多长时间,哪怕在没有恶意行为者、纯粹"好人场景"下,也可能因为权限设置过时而接触到不该看到的数据。他认为,企业现在需要一整套新的治理手段——审计追踪、更严格的访问控制、能快速拦截失控agent的能力——才能放心把更多自主性工作交给agent处理,这既会拖慢AI落地的节奏,也给安全创业生态带来了巨大机会。[关于OpenAI agent沙箱逃逸事件](https://x.com/levie/status/2082514776392175844)

### OpenAI, official account

OpenAI published a technical note arguing that benchmark scores reflect not just a model but a "bundle of less visible choices" about API settings, harness design, and prompting. Using their Responses API with retained reasoning and context compaction turned on — the same setup they use in their own products — GPT-5.6 Sol's score on a public agentic benchmark rose 188% while using 6x fewer output tokens than the default Chat Completions configuration, and they recommended developers adopt the same settings to get comparable results. [why harness settings matter for benchmarks](https://x.com/OpenAI/status/2082616643394703682) · [GPT-5.6 Sol's 188% score jump](https://x.com/OpenAI/status/2082616640144048433)

OpenAI发布了一篇技术说明,指出基准测试分数反映的不只是模型本身,还包括一系列不那么显眼的选择——API设置、harness设计和prompt写法。使用他们自家产品里采用的配置(Responses API,并开启retained reasoning和context compaction)后,GPT-5.6 Sol在一个公开agentic基准测试上的得分提升了188%,同时输出token用量还减少到原来的六分之一(相比默认的Chat Completions配置);他们建议开发者采用同样的设置,才能获得可比的结果。[harness设置为何影响基准测试](https://x.com/OpenAI/status/2082616643394703682) · [GPT-5.6 Sol得分提升188%](https://x.com/OpenAI/status/2082616640144048433)
