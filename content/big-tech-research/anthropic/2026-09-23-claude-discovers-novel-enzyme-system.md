**[Claude discovers a novel enzyme system with CRISPR-like repeats](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system)** — _Anthropic · Sep 23_

**Main takeaway:** Anthropic is standing up its own life sciences research group and wet lab, and shares a first result: with only a high-level prompt from scientists, Claude agents combed a massive DNA sequence database and found a previously unnoticed enzyme system built around a reverse transcriptase, flanked by an array of DNA repeats in a pattern reminiscent of CRISPR. Its function is still unknown.

**Main methods:**
- **Agents did the search, humans did the prompt and the bench work.** Anthropic's involvement was limited to the initial prompt and the lab experiments; the agents investigated distinct RT families and used their own judgement to pick interesting candidates.
- **Scale of the run.** Roughly 950 agents spent 21 hours searching the sequence database, burning about 210 million tokens, before one agent spotted the system.
- **What is actually new.** The underlying reverse transcriptase, from a jumbo phage, had been reported before; Claude appears to be the first to notice the system's defining features — an associated array of non-coding DNA sequences plus an extra accessory protein of unknown function.
- **Why the pattern matters.** That combination of characteristics has only ever been found together in a handful of other systems, all of which are programmable and cut, copy, or paste DNA — the class that produced CRISPR and several tools now in development.
- **A new lab, not just a model.** The group was formed in spring 2026 around the bet that agents should collaborate with humans at every step, which meant building one team that spans training Claude on biology and running the experiments.
- **External read.** Feng Zhang, a CRISPR genome-editing pioneer at MIT and the Broad Institute, reviewed the pre-print. Anthropic is explicit that the system's function has not been determined.

**[Claude 自己挖出一套带 CRISPR 式重复序列的新酶系统](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system)** — _Anthropic · 9月23日_

**Main takeaway:** Anthropic 组了个生命科学研究团队，还自建了实验室，这次放出第一批结果：科学家只给了一个大方向的 prompt，剩下的交给 Claude agent 去翻一个超大的 DNA 序列数据库，结果真找出一套以 reverse transcriptase 为核心、旁边还挂着一串 DNA 重复序列的酶系统，那个排布方式很像 CRISPR。它到底干什么用，目前还不知道。

**Main methods:**
- **人只负责出题和做实验。** Anthropic 这边只给了最初的 prompt，再加上后面的湿实验，中间翻数据库、分辨不同 RT 家族、判断哪个候选值得看，全是 agent 自己拿主意。
- **这一跑的规模。** 大约 950 个 agent 连着搜了 21 小时，烧掉 2.1 亿 token，最后其中一个 agent 注意到了这套系统。
- **新的地方到底在哪。** 核心那个 reverse transcriptase 来自一个 jumbo phage，之前的研究里已经报道过；真正没人注意到的是它旁边那串非编码 DNA 序列，还有一个功能未知的 accessory protein，这两个特征是 Claude 先看出来的。
- **这个组合为什么值得留意。** 这几个特征凑在一起，此前只在极少数几套系统里出现过，而那几套全都是可编程的，能对 DNA 做剪切、复制、粘贴，CRISPR 就出自这一类，另外几套现在也在被开发成工具。
- **建的是实验室，不只是模型。** 团队 2026 年春天成立，赌的是 agent 要在每个环节都跟人一起干，所以从教 Claude 生物学到实际上手做实验，全压在同一个团队里。
- **外部怎么看。** CRISPR 基因编辑的开创者之一、MIT 和 Broad Institute 的 Feng Zhang 看过这篇 pre-print。Anthropic 自己也说得很直白，这套系统的功能还没确定。
