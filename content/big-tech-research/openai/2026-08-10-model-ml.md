**[Model ML completes finance work more efficiently with GPT-5.6 Sol](https://openai.com/index/model-ml)** — _OpenAI · Aug 10_

**Main takeaway:** A customer story: Model ML routes its finance agents to GPT-5.6 Sol and reports 21% fewer tokens per PowerPoint deck than Fable 5 and 36% fewer tokens per Excel workbook than Opus 5 on its own Composite benchmark, with a bespoke tearsheet dropping from about an hour of analyst time to about five minutes.

**Main methods:**
- **A core planning agent with per-step model routing.** One central agent plans the assignment, picks tools, reconciles evidence, and runs calculations, sending each step to whichever model suits it — often GPT-5.6 Sol.
- **Native document tooling as the "last mile."** Model ML's own tooling emits editable PowerPoint and Excel files with traceable sources, so the deliverable is something that survives review rather than an analysis that stops short of a file.
- **Composite, an in-house financial-services eval.** In an Excel workflow on Composite, GPT-5.6 Sol used 36% fewer tokens per workbook than Opus 5; the post also headlines 21% fewer tokens per deck than Fable 5 and a percentage-point lead in "professional readiness" over Opus 5, though the body doesn't give that last figure.
- **Surface-agnostic continuity.** An assignment can start in email or the Model ML app and continue inside the Microsoft Office plug-ins without the user re-explaining context.
- **Excel from a template or from nothing.** The agent starts with a client template or a blank workbook, gathers the required data, builds formulas and logic across multiple tabs, then applies finance-specific formatting.
- **Volume, not just single deliverables.** In one workflow the agents processed virtual data rooms holding more than 100,000 rows and hundreds of files; a finance professional still checks assumptions, sources, and message before the work goes out.

**[Model ML 用 GPT-5.6 Sol 把金融活的"最后一公里"跑通](https://openai.com/index/model-ml)** — _OpenAI · 8月10日_

**Main takeaway:** 一篇客户案例。Model ML 的金融 agent 主要挂在 GPT-5.6 Sol 上，按他们自建的 Composite benchmark，出一份 PPT 比 Fable 5 少烧 21% token，做一个 Excel workbook 比 Opus 5 少 36%；以前分析师手搓一份定制 tearsheet 要一小时，现在五分钟就出货。

**Main methods:**
- **一个核心 agent 负责排活和路由。** 中枢 agent 先拆任务、选工具、对证据、跑计算，每一步再分给最合适的模型，多数时候就是 GPT-5.6 Sol。
- **自研文档工具专啃"最后一公里"。** 直接生成可编辑的 PowerPoint 和 Excel，每个数字都能追回来源，交出去的是能拿上会的文件，而不是停在分析阶段。
- **Composite 这个自建 eval。** Excel workflow 里 GPT-5.6 Sol 每个 workbook 比 Opus 5 省 36% token；官方还挂了"做 PPT 比 Fable 5 省 21% token""professional readiness 比 Opus 5 高几个百分点"，不过后面这个具体数字正文里没给。
- **换个界面不用重讲一遍。** 活可以从邮件起头，也可以在 Model ML app 里起头，接着切到 Microsoft Office 插件继续做，上下文自动跟着走。
- **Excel 空白模板都能起。** agent 拿客户模板或者空 workbook 开工，自己去找数据，跨多个 tab 搭公式和逻辑，最后再套上金融那套格式规范。
- **能扛量才是另一个卖点。** 有个 workflow 里，他们的 agent 啃完了十万多行、几百个文件的 virtual data room；不过东西发出去之前，假设、来源、结论还是得金融从业者自己过一遍。
