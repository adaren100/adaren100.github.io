**[Replit expands access to software creation with GPT-5.6 Luna](https://openai.com/index/replit)** — _OpenAI · Aug 19_

**Main takeaway:** A partnership post: Replit is launching Free Mode, powered by GPT-5.6 Luna, so users can plan and explore projects without burning usage. OpenAI's framing is that GPT-5.6 price performance plus its recent price cuts are what make an unmetered tier viable for millions of users.

**Main methods:**
- **Cost was the last barrier, not capability.** Replit says model cost — not model quality — was the final thing keeping software creation from being widely accessible; Luna is picked for the combination of capability, price performance, and reliable inference at scale.
- **Free Mode covers the pre-build loop.** Users get answers, suggestions, feedback, and analysis in seconds without consuming usage, aimed at the plan / ideate / shape / optimize stage before they commit to Build Mode.
- **Project context is the differentiator.** Because Agent already sees the full context of a user's projects, exploration happens in the same environment the idea will be built in, rather than in a separate tool.
- **Tiered routing between Luna and Sol.** When a task needs more advanced reasoning, Replit routes it to GPT-5.6 Sol and then drops back to Luna-powered Free Mode, preserving project context across the hop.
- **The stated goal is a 100× expansion of who builds.** Amjad Masad calls software "such an empowering tool" and argues that growing the number of people able to build by 100× is what actually widens the opportunity; Replit has been building on OpenAI models since GPT-3.

**[Replit 把 GPT-5.6 Luna 塞进 Free Mode，做东西不用再盯着 token 花销](https://openai.com/index/replit)** — _OpenAI · 8月19日_

**Main takeaway:** 一篇合作稿：Replit 上线 Free Mode，底下跑的是 GPT-5.6 Luna，用户想东西、理思路的时候不再消耗额度。OpenAI 想说的是，GPT-5.6 这一代的 price performance 加上他们最近几轮降价，才让"不计量的免费档"这件事在几百万用户规模上跑得起来。

**Main methods:**
- **卡住的一直是成本，不是模型能力。** Replit 说让"人人都能写软件"迟迟落不了地，最后那道坎是模型太贵。选 Luna 就是图它能力、price performance 和大规模 inference 的稳定性凑齐了。
- **Free Mode 管的是动手之前那一段。** 问答、建议、反馈、分析几秒就出来，而且不吃额度，覆盖的是想法成型前 plan、ideate、优化这些环节，真要开工再进 Build Mode。
- **真正的差别在于它知道你的项目。** Agent 本来就能看到用户项目的完整上下文，所以琢磨想法和把它做出来是在同一个环境里，不用切到另一个工具去。
- **Luna 和 Sol 之间会自动分流。** 碰上需要更强 reasoning 的活儿，Replit 会把它甩给 GPT-5.6 Sol，做完再退回 Luna 撑的 Free Mode，项目上下文一路带着走。
- **他们给自己定的目标是让能写软件的人多 100 倍。** Amjad Masad 说软件是个特别能赋能的工具，能动手做东西的人翻 100 倍，机会才算真的打开。Replit 从 GPT-3 时代就一直在拿 OpenAI 的模型搭东西。
