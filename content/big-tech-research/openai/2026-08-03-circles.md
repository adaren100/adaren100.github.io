**[Circles powers telco personalization with OpenAI technology](https://openai.com/index/circles)** — _OpenAI · Aug 3_

**Main takeaway:** Singapore-based telco SaaS company Circles built an AI Concierge on the OpenAI API that lifted ARPU by 22% and cut churn by 9% in Singapore, with its CareX multi-agent system reaching a 65% autonomous resolution rate for customer support.

**Main methods:**
- **AI Concierge as a unified interface.** Built on OpenAI's API platform, it merges search, account management, support, and personalized recommendations into one conversational experience instead of separate menus and repeated context.
- **CareX multi-agent architecture.** An orchestration agent tracks each customer's history and current activity, then routes requests to specialist agents handling billing, subscriptions, network management, and account services.
- **Context-aware routing.** The system picks up on real-time signals — like a customer browsing roaming options or investigating a billing issue — and routes to the right specialist without making the customer repeat themselves.
- **Codex for engineering velocity.** Circles reports improved development efficiency using Codex for design work, coding assistance, and unit testing.
- **Results.** 22% ARPU growth and 9% churn reduction in Singapore, plus a 65% autonomous resolution rate for CareX-driven customer support.

**[Circles 怎么用 OpenAI 技术做电信个性化服务](https://openai.com/index/circles)** — _OpenAI · 8月3日_

**Main takeaway:** 新加坡的电信 SaaS 公司 Circles 基于 OpenAI API 搭了个 AI Concierge，在新加坡把 ARPU 拉高了 22%，流失率降了 9%，背后的 CareX 多智能体系统客服自主解决率做到了 65%。

**Main methods:**
- **AI Concierge 是个统一入口。** 基于 OpenAI 的 API 平台搭建，把搜索、账户管理、客服和个性化推荐全揉进一个对话式体验里，不用再翻菜单、也不用反复讲同样的问题。
- **CareX 多智能体架构。** 一个编排 agent 跟着每个客户的历史和当下动作走，再把请求分派给账单、订阅、网络管理、账户服务这几个专职 agent 去处理。
- **懂语境的路由。** 系统能捕捉到客户在浏览漫游套餐、还是在查账单问题这类实时信号，直接分给对的专职 agent，客户不用重复说一遍。
- **Codex 提升了工程效率。** Circles 说他们在设计、写代码和做单元测试上用 Codex 之后，开发效率提高了。
- **实测结果。** 在新加坡 ARPU 涨了 22%，流失率降了 9%，CareX 撑起的客服自主解决率做到了 65%。
