**[Introducing OpenAI Presence](https://openai.com/index/introducing-openai-presence)** — _OpenAI · Jul 22_

**Main takeaway:** OpenAI launches Presence, an enterprise product for deploying trusted voice and chat AI agents in production, pairing model reasoning with policies, guardrails, and escalation rules so agents can handle jobs like billing issues or IT service requests reliably.

**Main methods:**
- **Job-scoped deployment.** Each Presence agent starts with one specific job (e.g., billing issues, insurance claims, IT requests) and receives only the knowledge and system access needed for that job.
- **Company-set policy layer.** Customers define what the agent can do, when it needs human approval, and when a person should take over.
- **Continuous improvement loop.** Production sessions and escalations surface gaps; Codex proposes updates that teams review and approve, letting agents adapt as customer behavior changes.
- **Full deployment support.** OpenAI works with each customer to identify high-value workflows, connect systems, set permissions, test the agent, and take it to production, with select systems integrators continuing support afterward.
- **Built from real deployments.** Developed in tight collaboration with OpenAI's Research team, drawing on years of enterprise-scale customer deployments to generalize insights back into the product.
- **Available today.** Supports real-time voice and chat use cases now, including customer support, outbound sales, and high-risk internal workflows.

**[隆重介绍 OpenAI Presence](https://openai.com/index/introducing-openai-presence)** — _OpenAI · 7月22日_

**Main takeaway:** OpenAI 推出企业级产品 Presence，专门用来把可信赖的语音和聊天 AI agent 真正落地到生产环境，把模型推理能力和policy、guardrail、升级规则打包在一起，让 agent 能可靠地处理账单问题、IT 请求这类具体工作。

**Main methods:**
- **按具体任务限定范围。** 每个 Presence agent 从一个具体任务开始（比如账单问题、保险理赔、IT 请求），只拿到完成这个任务所需的知识和系统权限，不多不少。
- **企业自己定policy。** 客户自己决定 agent 能做什么、什么时候需要人工审批、什么时候该转交给人。
- **持续迭代闭环。** 上线后的生产会话和升级案例会暴露出问题，Codex 会提出更新方案，团队测试通过后再上线，agent 就这样跟着客户行为的变化不断调整。
- **全流程陪跑。** OpenAI 和每个客户一起找出高价值workflow、接入系统、设定权限、测试 agent、推上生产，扩展阶段还可以由选定的系统集成商继续支持。
- **来自真实部署的经验积累。** 和 OpenAI 的 Research 团队紧密合作打磨出来的，背后是多年企业级部署积累的经验，反过来又持续改进产品本身。
- **现在就能用。** 目前已支持语音和聊天的实时场景，包括客服、外呼销售，以及一些高风险的内部工作流。
