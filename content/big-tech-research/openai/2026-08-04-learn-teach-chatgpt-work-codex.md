**[New ways to learn and teach with ChatGPT Work and Codex](https://openai.com/index/learn-teach-chatgpt-work-codex)** — _OpenAI · Aug 4_

**Main takeaway:** OpenAI introduced three new education plugins — one each for college students, K-12 educators, and college educators — that plug into ChatGPT Edu and ChatGPT for Teachers so students and teachers can use agentic AI on their own course materials without hand-crafting prompts.

**Main methods:**
- **Plugin = packaged workflow.** A plugin bundles apps, role-specific skills, instructions, and common workflows so users can start immediately instead of constructing complex prompts themselves.
- **Connects to existing tools.** Plugins tie into documents, course materials, calendars, and other approved apps so the assistant understands the context and task at hand.
- **K-12 Educator plugin.** Built alongside K-12 teachers to create differentiated resources, design interactive visuals, and surface actionable insights from materials teachers already use.
- **Learning Commons integration.** The K-12 plugin connects to Learning Commons, a philanthropic org building public AI learning-science datasets, letting teachers align materials to local academic standards while keeping control of grading and pedagogical decisions.
- **Deployment path.** Rolled out through ChatGPT Edu (institution-managed workspaces since 2024) and ChatGPT for Teachers (free for verified US K-12 educators/districts since 2025), both with FERPA-supporting privacy protections.
- **Guiding principle.** OpenAI frames the plugins around "AI should support learning, not shortcut it," keeping students and educators in control of agentic actions.

**[ChatGPT Work 和 Codex 上新的教与学玩法](https://openai.com/index/learn-teach-chatgpt-work-codex)** — _OpenAI · 8月4日_

**Main takeaway:** OpenAI 上线了三款教育插件，分别面向大学生、K-12 老师和大学老师，接入 ChatGPT Edu 和 ChatGPT for Teachers 之后，师生不用自己憋 prompt 就能让 agent 直接用上自己的课程材料。

**Main methods:**
- **插件就是打包好的工作流。** 一个插件里打包了应用、角色专属的 skill、指令和常见工作流，用户上手就能直接用，不用自己去构造复杂的 prompt。
- **能接上已有的工具。** 插件可以连文档、课程材料、日历和其他授权应用，这样 agent 才知道当下的语境和任务是什么。
- **K-12 老师插件。** 是跟 K-12 一线老师一起打磨出来的，能拿老师平时就在用的材料去做分层教学资源、做交互式可视化，还能挖出可执行的洞察。
- **接入了 Learning Commons。** K-12 插件对接了 Learning Commons（一个做公共 AI 学习科学数据集的公益组织），老师可以把材料对齐到当地的学业标准，同时评分和教学决策还是自己说了算。
- **落地方式。** 通过 ChatGPT Edu（2024 年上线的机构托管工作区）和 ChatGPT for Teachers（面向经认证的美国 K-12 老师和学区，2025 年起免费）铺开，两者都有支持 FERPA 的隐私保护。
- **背后的原则。** OpenAI 给这套插件定的调子是"AI 应该辅助学习，而不是抄近道"，师生始终对 agent 的行为保有控制权。
